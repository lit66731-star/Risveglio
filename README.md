# Risveglio

统一剧情智能面板（SillyTavern 第三方扩展）。

- **视觉**：冷静 / 深邃 / 精密 / 未来感 / 运行中的生命感 —— 黑灰米白骨架，识别色（强调色）暂未定
- **结构**：底部悬浮胶囊 Dock（视觉标志）+ 多页；Dock 支持横向滚动、图标 + 短标题、当前页高亮、状态 Badge、切页动画、「···」扩展入口
- **当前状态**：空白框架（v1.0.0）—— 只搭好了面板壳与视觉，各模块内容后续逐个填充

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `manifest.json` | 扩展清单 |
| `index.js` | 面板骨架：顶栏入口按钮 + 底部悬浮胶囊 Dock + 多页切换 |
| `style.css` | 视觉 token + Dock + 空态（黑灰米白骨架） |

## 版本号规则

从 `1.0.0` 起，每一段满 20 向前进位（0~19 循环）：`1.0.0 → 1.0.1 → … → 1.0.19 → 1.1.0 → … → 1.19.19 → 2.0.0`。

## 安装

1. 下载本仓库，放入 SillyTavern 的 `data/default-user/extensions`（或通过扩展管理安装）。
2. 启用 Risveglio，顶栏出现入口按钮，点击打开面板，底部胶囊 Dock 切换页面。
